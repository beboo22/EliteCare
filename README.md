# EliteCare

EliteCare is a comprehensive healthcare management system built with .NET 8.0. It provides functionalities for managing appointments, authentications, authorizations, bills, departments, doctors, nurses, patients, receptionists, and specialist doctors in departments.

## Features

- **Appointments**: Manage patient appointments.
- **Authentications**: Sign in with Facebook and Google.
- **Authorizations**: Role-based access control.
- **Bills**: Manage billing information.
- **Departments**: Manage hospital departments.
- **Doctors**: Manage doctor information.
- **Nurses**: Manage nurse information.
- **Patients**: Manage patient information.
- **Receptionists**: Manage receptionist information.
- **Specialist Doctors in Departments**: Manage specialist doctors in various departments.
